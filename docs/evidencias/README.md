Las cuentas, el alojamiento y las comodidades son datos de demostración; no representan usuarios reales ni incluyen contraseñas.

Las imágenes 18 y 19 muestran el texto capturado de los comandos, renderizado para lectura; no son fotografías de la terminal del estudiante. Los archivos npm-test.txt y npm-build.txt conservan la salida completa. integracion.json contiene las aserciones aprobadas contra la API real. instalacion-limpia.txt acredita la instalación desde una copia local sin dependencias.
